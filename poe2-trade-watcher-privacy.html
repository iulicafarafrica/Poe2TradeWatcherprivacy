Privacy policy

Poe2 Trade Watcher 2.5.0 · last updated 27 October 2026

Poe2 Trade Watcher is an unofficial fan-made browser extension. It has no accounts, no analytics, no ads and does not sell or share data with anyone.

What is stored on your device

Saved trade items, gear imported from a build, builds, watched listings, pinned items, search history, price history snapshots and settings are stored locally in your browser profile (chrome.storage.local). Price history keeps the last 50 price checks of each item you save or watch. None of it leaves your device unless you export a backup or enable Chrome Sync.

The same local storage holds small caches that avoid repeated work, for example: item pictures taken from the trade pages you saved (capped at a few hundred), the public Craft of Exile data files (kept for 12 hours) and recently fetched currency rates. Removing the extension deletes all of it.

Build import

Build codes from Path of Building 2, pobb.in or Mobalytics ("Share your Build") are decoded inside the extension, on your own device. Pasting a code contacts no server and opens no build page. The code itself is not kept: only the equipped gear you choose to import is saved, as ordinary items inside a build. Flasks and gems are skipped, and no item pictures are fetched for imported gear.

Importing gear itself sends nothing and asks for no permission. The first time you press "How to craft" on an imported item, Chrome may ask for the optional Craft of Exile host permission; if you allow it, the extension reads the site's public data files once to fill in affix names and remembers the result. If you decline, everything else keeps working, only the affix names cannot be matched.

Optional Chrome Sync

If you enable "Sync settings with Chrome Sync", your settings are stored in your Google account through Chrome's built-in sync (legacy bookmark data from older versions, if any, is included). Saved items and watchers are never synced. Google's privacy policy applies to that storage.

Network requests

  • www.pathofexile.com – reads public trade listings of the page you are viewing (item data, seller character name, whisper text, price, stash position). The same public trade API is used to fetch the details of a single listing when you save it, watch it, copy its whisper or refresh its price, so the stored data matches the page. Watcher refreshes reuse your existing Path of Exile session so the public API can answer them; the extension never sends your session data anywhere else. A single search is created through the same API when you ask for an item's trade link.
  • poe.ninja – fetches public currency exchange rates used to convert prices.
  • mobalytics.gg – only if you click "Read page": the pictures and trade links of the build page you already have open are read from that tab and copied onto your saved items. The optional host permission is requested at that click, never at install, and reading the page sends no request anywhere.
  • beta.craftofexile.com – only if you open a Craft of Exile link (including "How to craft" on an imported item), or import a build while that permission is already granted. It downloads the public data files the Craft of Exile site itself loads (base item ids and modifier tables) so the item can be opened with its modifiers. The optional host permission is requested on the first such click, never at install. The files are cached in your browser profile for 12 hours. These downloads carry nothing about your items; item text travels inside the tab address instead (see Craft of Exile links).
  • Discord webhook and ntfy – only if you configure them. Alerts you enable (item sold, price change, target reached, whitelisted seller) are sent to the endpoint you provide and contain the item name, price and seller character name. Discord needs an optional host permission (discord.com and the legacy discordapp.com), requested the first time you save or test a webhook, never at install. For ntfy.sh the same optional permission is requested on demand; a self-hosted ntfy URL is contacted directly at the address you enter.

Craft of Exile links

The "How to craft" and "Copy for CoE" actions open a Craft of Exile page in a new tab. The item text is carried inside that page's address (eimport=), so Craft of Exile receives the item when the tab loads; that is how the import works. The extension does not upload the item anywhere else and never sends your items to Craft of Exile from the background. Items imported from a build use exactly the same link. For unique items, and to fill in affix names on imported items, the extension also reads the site's public data files (see Network requests above); nothing else is downloaded or sent.

Secrets never leave your profile

The Discord webhook URL, the ntfy topic and whisper tokens are kept in local storage only. They are removed from exported backup files and are not included in Chrome Sync payloads, so they are never uploaded to your browser account or to a backup file you share.

What is never collected

No email, no passwords, no browsing history outside the Path of Exile trade searches you make yourself, no location, no tracking and no telemetry. The extension reads only the official Path of Exile trade pages it is installed on, plus a build page you explicitly ask it to read with the optional permission above. Build codes you paste are decoded on your device and are never uploaded.

Your control

  • Remove alerts by clearing the Discord webhook or ntfy topic in Settings.
  • Delete saved or imported items with the delete button, delete a build to drop the gear it brought in, and erase everything by removing the extension.
  • Export a full backup any time from Settings.
